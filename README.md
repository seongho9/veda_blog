## Required Libraries
- Boost 1.75.0
- GTest
- ODBC
## Build
```bash
mkdir build && cd build
cmake ..
make
```
### Execute(Build Required)
in project root path
```bash
./build/src/main
```
### Test(Build Required)
in project root path
```bash
./build/test/main
```
